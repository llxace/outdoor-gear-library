# 户外装备库 iPadOS 版

原生 SwiftUI iPad 应用，移植 Mac 主程序的业务模块和 v9 数据格式，并针对 iPad 侧边栏、分栏浏览和触控文件操作适配。资料保存在本机；不同设备之间通过导入导出迁移，不自动同步。当前源码包不包含任何用户库存、照片、头像、行程或备份。

## 功能

- **仪表盘与装备库**：装备总量、花费、品牌/分类/状态统计；装备档案、数量、重量、购买信息、位置、标签、备注、照片和附件；搜索、收藏、批量编辑、复制、分类管理及回收站。
- **打包与借用**：库存数量约束、装备筛选、携带重量和价值统计、跨用户借用、撤销及清空；路线选择、轨迹组合、里程/海拔信息、出发时间天气和远期趋势。
- **路线与地图**：内置路线资料、名称/地点在线搜索、GPX/KML 导入、路线地图和自定义组合。
- **路餐与饮水**：按天、同行人数和餐次规划；重量、热量、价格、准备状态、每日目标、预算、备用粮、携带水、购物清单，以及相机/照片食品标签 OCR。
- **徒步历史**：从打包生成或手动建立记录，保存日期、路线/轨迹、天气、感受、日志和装备快照；支持检索、编辑、年份筛选及历史装备调整。
- **照片与个人资料**：主图、附加照片及文件；方形商品图、白底和阴影处理、恢复原图；多本地用户独立装备库、头像、设置和资料切换。
- **数据与设置**：Excel 表格字段映射和预览、CSV/TSV 导入导出、含照片和附件的完整备份恢复；主题、库名、货币、自动编号、附件复制等设置。

## 数据迁移

首次启动时应用会在 iPad 应用沙盒创建空白资料库；所有记录随后保存在 iPad 本机。应用包不携带开发者的私人资料。系统文件选择器用于导入，系统分享面板用于导出或分享。

## 安装说明

GitHub 上的开发预览构建为未签名 IPA，不能直接安装到普通 iPad。正式面向用户分发需要 Apple 的签名和分发流程（例如 TestFlight 或 App Store）；个人设备测试也需要签名及对应的设备配置文件。源码可用 Xcode 打开并自行构建。

## 构建

在 Xcode 打开 `户外装备库iPadOS.xcodeproj`，选择 `OutdoorGearPad` scheme 和 iPad 模拟器或设备运行。最低部署版本为 iPadOS 17，target 设备族为 iPad。`Resources/NOTICE.md` 列出随应用分发的路线资料及上游软件许可。
