# 历史记录的装备整理

## 使用方式

在历史记录的「编辑」页面：

- 「从装备库选择…」打开装备选择页，支持名称、品牌、型号、分类、标签、备注搜索，分类筛选及批量选择。已记录的自有装备不可重复添加。
- 「从当前打包添加装备」复制当前打包资料，保留借用来源；不会覆盖已记录的历史重量、数量或备注。
- 「手动添加装备」补录以前用过、现在装备库中已没有的装备。
- 清单可按名称等资料搜索、按分类筛选；每行可直接填写实际携带数量、单件重量，展开后修改分类、品牌、型号及当次使用感受。
- 保存后的详情按分类整理，并显示分类重量小计、每件装备的数量、重量及使用备注。

历史装备保存为独立快照：历史数量可以大于当前库存，当前的损坏状态不影响过去的记录；修改历史资料不会改变装备库或当前打包。单件零重量沿用「重量待补」含义，不计入已知重量。数据格式保持版本 9。
