应用界面

让清单跟着旅程走。

界面预览使用虚构的演示装备；没有展示或上传个人装备数据。

所有预览均为虚构演示数据，不含真实用户档案、装备清单或照片。

设计原则

资料留在本机。
出发时再连接世界。

装备资料、照片、备份和徒步记录保存在本机。在线路线、天气与汇率功能会访问相应服务。应用源码和路线数据库采用不同许可，来源与声明都在仓库中列出。
