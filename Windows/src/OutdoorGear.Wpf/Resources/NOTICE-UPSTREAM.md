# 第三方数据与服务说明

内置 `DomesticRoutes.json` 的元数据将路线数据归于 OpenStreetMap contributors 与 Waymarked Trails，并声明数据库采用 ODbL-1.0。路线数据库按其来源和许可说明单独提供。

- OpenStreetMap：© OpenStreetMap contributors，ODbL 1.0。
- Waymarked Trails：路线数据来源之一，按随数据提供的 ODbL 声明保留署名。
- Open-Meteo：天气、地理编码和海拔服务；在线功能需遵守服务方条款。
- 地图瓦片在界面显示 OpenStreetMap 署名。离线缓存写入系统临时目录。
- 卫星影像由 Esri World Imagery 缓存地图服务提供；按服务元数据显示 `Source: Esri, Vantor, Earthstar Geographics, and the GIS User Community`。服务说明与使用条款入口：https://goto.arcgisonline.com/maps/World_Imagery 。影像瓦片缓存写入系统临时目录。
