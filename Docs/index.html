FIELD GUIDE
功能指南 / 2026
装备档案01 / GEAR

把装备资料，
整理成自己的库。

记录名称、品牌型号、分类、数量、重量、价格、状态、标签与备注；管理照片、附件和组合装备，也可用可选工具整理产品照。

  • 分类浏览、搜索与概览统计
  • 收藏常用装备，维护库存与状态
  • 多用户本机资料库，可在清单中借用他人装备
查看装备管理源码 ↗ G
行前打包02 / PACK

选好这次带什么，
重量跟着汇总。

从装备库选择物品并填写携带数量，查看已知重量、装备价值与未补全项目；损坏装备不会加入清单。

  • 按分类筛选，也可只看已选物品
  • 自有装备与借用装备合并计算
  • 清空清单后可撤销恢复
查看打包功能源码 ↗ P
路线与天气03 / ROUTE

先看路线，再看天。

导入 GPX / KML，或按地名和路线名称搜索。预览地图、距离与海拔；可组合多段路线，并查看出发时段天气、逐日预报和远期趋势。

  • 内置国内路线目录，另有在线路线搜索
  • 海拔统计会标明轨迹数据或地形估算来源
  • 天气和路线搜索需要联网，覆盖因地区而异
路线源码 ↗天气源码 ↗
R
路餐与饮水04 / FOOD

把每天的补给，
也算进行程。

按天数、餐次和人数安排食物，记录份数、包装重量、热量、价格与准备方式；汇总每日能量、总重量、预算和出发携水量。

  • 生成可复制的采购清单
  • 根据已录食物提供路餐建议
  • 本机拍照识别营养标签，结果先核对再保存
查看路餐功能源码 ↗ F
徒步历史05 / LOG

走过之后，
再把细节留下。

从当前打包清单生成记录，或手动补录日期、路线、游记、天气与感受。轨迹、当次装备快照和实际数量各自留在这次历史里。

  • 按年份浏览，搜索路线和游记
  • 查看历史路线图与当次装备重量
  • 修改历史装备不会改动当前库存
查看徒步记录源码 ↗ L
资料迁移与整理06 / KEEP

旧表格能接上，
本机资料也能带走。

Excel 导入支持预览与字段匹配；CSV / TSV 可导入，CSV 可导出。当前用户的完整备份包含资料、清单、照片和附件，恢复时按编号合并。

  • 自动编号、批量编辑、复制与回收站整理
  • 设置外观、资料库名称与显示货币
  • 汇率按需刷新，作为价格参考
导入导出源码 ↗用户资料库源码 ↗
