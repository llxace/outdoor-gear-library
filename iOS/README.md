# 户外装备库 iPhone 版

原生 SwiftUI 徒步装备管理应用，支持 iOS 17 及以上。数据仅保存在设备本地，Mac、iPad 和 iPhone 之间不会自动联网同步。

## 功能

- **装备管理**：装备浏览、搜索、分类、编辑、照片管理和回收站。
- **行前打包**：按库存数量添加装备，统计重量和携带装备价值；可加入同行者的装备。
- **路线与天气**：公开路线目录、在线路线搜索、GPX/KML 文件导入、出发日期和天气预报。
- **徒步记录**：查看历史行程及当次装备快照。
- **数据迁移**：导入和导出 JSON；完整 ZIP 备份包含照片与附件。导入会替换本机资料并在操作前确认。
- **外观设置**：深色和浅色外观。

## 隐私与数据

公开源码和安装包使用空白初始资料，不含个人装备清单、照片、头像、文件、徒步历史或备份。首次启动会在本机创建空白装备库；公开路线数据及其来源说明保留在 `Resources/`。

应用数据保存在设备本地。在线路线搜索和天气查询需要网络；数据导入导出由用户通过系统文件选择器操作。

## 安装包说明

GitHub 提供的是**未签名 iOS 开发预览包**。它用于源码审阅和开发验证，普通 iPhone 不能直接安装。安装到自己的设备需要使用 Xcode 和 Apple 开发者签名；面向公众分发需由开发者通过 TestFlight 或 App Store 提供签名版本。

## 从源码构建

用 Xcode 打开 `户外装备库iPhone.xcodeproj`，选择 `OutdoorGearPhone` scheme 和 iPhone 模拟器或设备。项目最低版本为 iOS 17。未配置开发者账号时可构建模拟器；真机安装需要个人开发者签名。

功能架构见 [ARCHITECTURE.md](ARCHITECTURE.md)。路线目录及许可归属见 [Resources/NOTICE.md](Resources/NOTICE.md)。应用使用 GNU AGPL-3.0，第三方数据与组件按各自许可提供。
